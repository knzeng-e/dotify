# Dotify logo pack

The Polkadot ring of six dots with a stylised G clef at the centre. The dots stay pink; the clef carries the contrast colour, so the mark reads on any support. The clef is drawn as vector outlines, so every SVG here is self-contained and needs no music font.

## Mark
- dotify-mark-light.svg : ink clef, for white and light backgrounds
- dotify-mark-dark.svg : white clef, for dark backgrounds
- dotify-mark-light-1024/512/256.png, dotify-mark-dark-1024/512/256.png : transparent raster

## Lockups
- dotify-logo-light.svg / dotify-logo-dark.svg : horizontal, mark + wordmark
- dotify-logo-stacked-light.svg / dotify-logo-stacked-dark.svg : mark above the wordmark, for posters and square formats
- dotify-banner-light.svg / dotify-banner-dark.svg (+ .png) : wide banner with the tagline, for headers and social covers
- dotify-mono-ink.svg / dotify-mono-pink.svg / dotify-mono-white.svg : one colour, for stamps, merch, engraving and low quality print

## App and web
- dotify-app-icon-ink.svg / dotify-app-icon-pink.svg (+ 1024/512/256 png) : rounded square app icon
- dotify-favicon.svg : mark with slightly fatter dots, for small sizes
- dotify-favicon-ink-square.svg (+ 16/32/64/180 png) : the version that survives a browser tab

## Colours
- Pink #E6007A, dots
- Ink #0B0B12, clef and wordmark on light
- White #FFFFFF, clef and wordmark on dark

## Notes
- Clear space: keep at least one dot width of empty space around the mark.
- Minimum size: 24 px for the full mark, below that use the favicon file.
- The wordmark is set in Manrope ExtraBold, letter spacing -1. In the SVG lockups it is live text; outline it in a vector editor if the target machine has no Manrope.

## Result and decisions

W18 delivers a privacy contract for nearby room discovery before Dotify collects
any real location. The result is a design record, an inert typed protocol
proposal, a synthetic privacy simulation, and documentation updates that keep
public Product claims honest.

Nearby discovery is allowed only as an opt-in layer over ordinary room links.
Hosts separately choose whether one live room appears nearby, and listeners
separately choose whether to search by device area, manual area, or venue QR.
Exact coordinates remain device-side and must not cross the network, logs,
durable stores, chain, Statement Store, or public room state.

The proposed protocol carries coarse area cells, rotating discovery IDs, short
expiries, existing public room metadata, canonical room URLs, and bucketed
counts. It deliberately excludes wallet addresses, Product public keys, IP
addresses, latitude/longitude fields, geohashes, exact distance values, and
exact counts below useful density. Coarse cells reduce precision but do not
provide anonymity; small crowds, timing, IP metadata, and room copy can still
leak context.

The W19 implementation gate is intentionally strict: first implementation must
stay behind a feature flag, use an ephemeral server-side store, keep exact
coordinates in short-lived device memory only, pass protocol safety tests, and
record manual smoke for permission denial, sparse area expansion, revocation,
expiry, and wallet-free joining.

Current official browser and Product documentation checked on 2026-09-13:

- W3C Geolocation Recommendation:
  https://www.w3.org/TR/geolocation/#privacy_considerations
- MDN Permissions API:
  https://developer.mozilla.org/en-US/docs/Web/API/Permissions_API
- MDN Permissions-Policy `geolocation`:
  https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Permissions-Policy/geolocation
- Polkadot Desktop permissions:
  https://docs.polkadot.com/reference/apps/hosts/polkadot-desktop/permissions/
- Product SDK host API:
  https://paritytech.github.io/product-sdk/api/host/

No Product-native location capability was treated as available. Product Desktop
nearby remains unknown/unsupported until official API evidence exists for this
app; safe Product paths are manual area, venue QR, or external-browser
continuation.

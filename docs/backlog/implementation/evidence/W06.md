## Result and decisions

W06 removes the public passkey-only wallet path instead of attempting to harden
WebAuthn PRF account recovery for the pilot. The old route could derive a
different EVM account when local credential metadata was lost, the origin/RP
changed between standalone web and Product surfaces, the authenticator lacked
PRF support, or a user accidentally created a new passkey. That failure mode is
worse than asking for an explicit EVM wallet when money or artist publishing is
involved.

Dotify now exposes two public account authorities:

- EVM wallet providers for paid access and artist/runtime writes in the tracked
  standalone and Product builds.
- Product host accounts for presence, rooms, protected playback key/session
  proofs, and Product CDM writes only when that adapter is explicitly selected
  and smoke-tested.

Room joining and Free playback stay walletless. The wallet modal is now
contextual: it says to listen first and connect only for paid, protected, or
artist actions. Legacy browser-local passkey lookup data is detected only so the
user can forget Dotify's old `localStorage` value; the UI does not call
`navigator.credentials`, does not restore `dotify:wallet:lastMethod=passkey`,
and does not imply that deleting the local value removes an operating-system,
password-manager, or hardware passkey.

The rejected alternative was to implement discoverable WebAuthn PRF recovery in
this slice. The release condition in W06 says to keep risky enrollment off when
recovery cannot be proven on target authenticators. Because this environment
cannot validate target authenticators, Product host versions, browser PRF
support, and origin migration end to end, the implementation retires
passkey-derived account creation for the pilot and documents passkeys only as a
future authentication/recovery factor attached to an existing EVM wallet or
Product host account.

The Product executable version is bumped to `[0, 1, 17]` because the Product
bundle changes account-route behavior and cache-sensitive wallet UI.

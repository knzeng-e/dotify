## Result and decisions

Hosts must now choose a real room name before opening a room; the untouched
`Listener` seed and signaling fallback `Host` are never presented as people.
The chosen Product username or saved alias still seeds the field. The room
shows its code once and, while the host is alone, makes one invitation surface
prominent with copy-link, QR, and native share where the browser supports it.

Guests retain the shared progress bar, local play/pause, and volume. Host-only
shuffle, skip, and repeat actions are absent rather than disabled. The
signaling protocol, host authority, guest entry policy, and protected-audio
boundary did not change. Guests still enter with a name and room link without a
wallet, signature, payment, or content key.

Room discovery removes summary metrics and routine manual refresh. Refresh is
available only while signaling is degraded; renderer controls disappear when
there is no room, and galaxy navigation controls disappear when one room gives
them nothing to navigate. Legacy rooms without a chosen host name use neutral
copy. The join sheet uses the existing live-room green and avoids automatically
opening a touch keyboard.

## Result and decisions

W10 keeps Dotify's existing deep-blue, cyan, Polkadot-pink, artwork-led, editorial identity, and applies it to a small production-relevant slice: discover an open room, inspect its host/track/stream/presence context, then join through the existing room entry handler.

The room cards and 2D sky now select a room instead of immediately joining when the Rooms view provides an inspection target. The join action remains in one place, the detail surface, and still routes through the existing display-name threshold flow. Full rooms remain inspectable but cannot be joined. Room signal states are visible in the live section and the empty state distinguishes unavailable signaling from a genuinely empty room list.

The new `RoomDiscoveryRenderer` component is the renderer boundary for later 3D work. It currently exposes only the honest DOM/CSS `sky-2d` renderer and does not add a graphics library. Mobile and reduced-motion users still rely on the room list and bottom sheet, not the sky.

Shared tokens now cover safe-area insets, touch targets, selected surfaces, sheet surfaces, and layout gaps. The Product app bundle version is bumped to `[0, 1, 18]` because this changes the Product-delivered UI.

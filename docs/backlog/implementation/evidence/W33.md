## Result and decisions

[ADR 0034](../../../adr/0034-media-cdn-and-native-storage.md) selects the owner's
existing Pinata dedicated gateway/CDN rather than adding a second provider.
`VITE_DOTIFY_MEDIA_EDGE_URL` sets edge-first public ciphertext reads, preserving
API/IPFS recovery. `MEDIA_EDGE_URL` enables bounded API warming after durable
confirmed catalog sync. `MEDIA_IPFS_GATEWAY` optionally prefers the dedicated
Pinata origin on API misses. Defaults are unchanged until provider activation;
this is infrastructure selection, not an optional listening capability.

The existing API read-through and v3 authentication are reused. No old DAV2
reader, byte-range playback, key cache, plaintext cache, custom Worker or new
account is introduced. Public CDN objects are addressed only by CID/fixed path,
without tokens/cookies. Host room Remote permissions include the configured edge.

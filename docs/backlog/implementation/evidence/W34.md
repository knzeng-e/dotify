## Compatibility and operations

No dependency, key derivation, signature format, contract, secret, persistence
schema or new environment variable changes. This uses current v3 streaming only.
Client keys are never persisted; clearing means dropping memory references, not
promising cryptographic erasure or revocation of already delivered material.

Deploy API before Web/Product, retaining single-track routes and W30 proxy
configuration. A missing/unavailable batch remains a cold-path fallback without
a speculative signature prompt. Roll back clients first; retain all key custody,
nonce/revocation and catalog files. Process restart only clears verdicts.
See [deployment configuration](../../../operations/deployment-configuration.md).
No deployment, runtime write, wallet approval or payment occurred for W34.

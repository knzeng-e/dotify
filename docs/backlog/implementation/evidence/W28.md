## Result and decisions

The room dock already had the correct track authority from #216. W28 retains
`playbackTrack` and verifies it while a guest browses Music and the host changes
track. A single touch-sized metadata button now returns to the room, with live
context and host name. Direct listening keeps its simpler track identity.
Presence comes from the signaling session; reconnecting views suppress stale
counts rather than claiming that disconnected participants are still present.

Music uses the existing horizontal catalog with native touch scrolling, scroll
snap and a next-card glimpse. Mobile arrow buttons are removed; search and the
rail/grid icon share one row. Existing artwork/title/artist cards, desktop hover
play and access sheets are reused, not replaced with another discovery system.

The mobile solo player has a dedicated return control instead of competing
global navigation. Seek, previous/play/next, and secondary shuffle/repeat/queue/
artist-support/mute remain available. The desktop stage is unframed but uses
the same controls. Icon hit targets do not grow into one another at 200% text.
The support sheet uses a compact heading and fixed-size lock icon; dismissal
is tested after scrolling at 200% text. The dock is almost opaque so the
catalog underneath does not compete with its current track identity.

`PlayerQueueDialog` reads the existing controller's current/next selection.
It does not introduce another persistent queue or autoplay policy. Additional
catalog entries are explicitly labelled "More music", not an invented ordered
queue; repeat does not claim that another track is next. Selecting a release
calls the normal access-checked `openTrack` path. Existing bounded prefetch
handlers remain on previous/next and selection intent.

Room tabs are Chat / Queue / People. Queue brings `HostLineup` and
`RoomRequests` together, with host mutation controls still unavailable to
guests. Panels retain their drafts. Writing mode keeps the composer reachable;
at very large text the room can scroll instead of collapsing the conversation.
No session, audio controller, signaling, contract, entitlement or key-delivery
authority moved into the view layer.

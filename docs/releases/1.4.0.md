# Dotify 1.4.0: find your people, listen together

Published from final `main` commit
`9788ec0b097dcf3144082ad180c0d0e59ee81650`, after [#314](https://github.com/knzeng-e/dotify/pull/314).
This is a **testnet prerelease**. The public pilot acceptance in
[#158](https://github.com/knzeng-e/dotify/issues/158) remains open.

## What changes since 1.3.0

- **Find a shared moment.** Nearby discovery starts automatically with location
  consent and a range up to 42 km. Opted-in Worldwide rooms appear even without
  a local fix. Rooms start Link only; discovery never becomes a directory of
  private rooms or precise positions.
- **A living room galaxy.** Circular covers, orbiting presence, exact session
  counts, bounded growth/light and a neon Dotify radar identify active rooms.
  Your own room is marked. Optional room names and invitations survive track
  changes, and a visible artist badge requires an announced, verified visit.
- **Less friction around rooms.** Link/QR invitations, clearer nickname entry,
  progressive results, reversible Hide and scoped live updates bring discovery
  and room presence together. Artist activity includes private-room totals
  without disclosing private room identifiers.
- **More resilient listening and sign-in.** Protected playback has bounded,
  coalesced/cancellable ciphertext recovery and an API media relay. Failed
  sign-outs retain inactive, API-scoped revocation credentials for recovery;
  late responses cannot silently revive stale credentials or overwrite newer
  payment feedback. Existing access checks and authenticated decryption remain.
- **Clearer artist support.** Tips/gifts, paid listening access and artist
  earnings have separate presentation and verification. Sign-in preserves a
  contribution draft, then refreshes its quote. Pending receipt checks do not
  resubmit a payment or assume failure from elapsed time.
- **Calmer mobile forms.** Shared sheets and visual-viewport handling keep
  fields above the keyboard, preserve drafts and reduce accidental focus.
- **Documentation that starts with the task.** Shorter project/developer
  READMEs, listening/local-development/payment-recovery guides, corrected
  architecture explanations and five reproducible interface captures. The
  galaxy capture opens three real local rooms; people, artwork and releases
  are explicitly demonstration data.

- Deployed Web checks at desktop/mobile sizes pass: live temporary Worldwide
  room, profile preview, reversible hiding, no page errors or horizontal
  overflow, and a browser ciphertext Range read. The temporary room was closed.
  Simulated mobile keyboard geometry preserves visible labels/fields and drafts.
- Installed Product Desktop Dev 0.1.3 loads Dotify and its room form. Room name
  and invitation entry work; the form was dismissed without creating a room.
  The owner accepted the font-domain prompt. Native location still returns the

- Full physical-device audio/background/location coverage, native funded receipt

  owner-confirmed mobile keyboard behavior is historical evidence, not a new
  full device-matrix pass.

Open draft [#312/W32](https://github.com/knzeng-e/dotify/pull/312) streaming encoding
is excluded. DAV2 remains the audio format. Edge delivery, SFU scaling, CASH
settlement and universal native location/media/personhood support are not
promised. Keep [#158](https://github.com/knzeng-e/dotify/issues/158) open pending
its measured pilot go/no-go decision.
